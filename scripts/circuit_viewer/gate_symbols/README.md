# Gate symbol assets

These SVG symbols are adapted from the digital gate templates in
NetlistSVG's `lib/default.svg`, with additional three-input variants and a
normalized `60 x 50` view box for this viewer. NetlistSVG is Copyright (c)
2016 Neil Turley and distributed under the MIT License. See
`NETLISTSVG-LICENSE.txt` in this directory.

The symbol boundary is also its routing contract: inputs terminate at `x=0`,
the output terminates at `x=60`, and pin Y positions are `25` for one input,
`16/34` for two inputs, and `12/25/38` for three inputs.
